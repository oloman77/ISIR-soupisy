# ISIR crawler + GitHub Pages

1. Nahraj celý obsah projektu do veřejného GitHub repozitáře.
2. Settings → Pages → Source → GitHub Actions.
3. Actions → ISIR crawler + Pages → Run workflow.
4. Po úspěchu se zobrazí URL webu.

Workflow běží automaticky každé 2 hodiny.
První běh může trvat déle, další už navazují od uloženého current_id.
